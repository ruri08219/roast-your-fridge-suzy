Entry for the [make.fun](https://make.fun) competition
[One Line, One Laugh: Roast Your Fridge](https://make.fun/bounty/u-suzy-one-line-one-laugh-roast-your-fridge-f1063521)
— one line (at most 200 characters) roasting our fridge.

## The entry

> My fridge screams if the door stays open ten seconds, yet it has watched the same leftovers rot for three weeks without saying a word.

134 characters, one sentence, no trailing newline. The door alarm is the
fridge's loudest feature — and its silence about three-week-old leftovers
is the twist.

## Run it

```sh
python3 src/main.py
```

Writes `entry.txt` to `$OUTPUT_DIR` (default `/output`). Exits 0 on a valid
entry; exits 1 (writing nothing) on an empty, over-long, multi-line, or
control-character entry.
